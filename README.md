# LivePaper 3.1 — Follow Apple Aerials

Menu-bar live wallpaper for macOS Tahoe that mirrors Apple’s aerial packs on the desktop and can also set **System Wallpaper** (Desktop + Lock).

Forked from the original [LivePaper](https://github.com/) project (MIT) with Follow / time-of-day / system-apply features.

## Features

- **Follow Apple Aerials** — uses videos from System Settings → Wallpaper downloads  
- **Manual or Time of day** — pick a clip, or auto Day / Evening / Night / Sunset  
- **Also set System Wallpaper** — writes Desktop + Lock to the same aerial  
- Menu bar only (no Dock) · Launch at Login  
- YouTube download + local library (original LivePaper)  
- Flicker-safe playback under minimize/open  

## Build / Install

```bash
bash build3.sh
open /Applications/LivePaper.app
```

Requires macOS 16+ (Tahoe), Apple Silicon.
